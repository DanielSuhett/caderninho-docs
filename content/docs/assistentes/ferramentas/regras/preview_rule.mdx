Regras de classificação · Simular · Consulta / prévia

## Efeito da chamada

Consulta ou simula sem gravar alterações financeiras nem iniciar uma importação.

## Parâmetros

| Campo | Obrigatório | Tipo | Uso |
| --- | --- | --- | --- |
| `accountId` | Não | texto ou null | ID de conta devolvido por get_accounts. Padrão: null. |
| `direction` | Não | "DEBIT" / "CREDIT" ou null | Direção DEBIT ou CREDIT. Ela não determina, sozinha, despesa ou receita. Padrão: null. |
| `filter` | Não | objeto ou null | Filtro composto da ferramenta; veja objetos, alternativas e condições no schema. Padrão: null. |
| `spaceId` | Sim | texto | Espaço da instalação. Consulte get_spaces; o espaço inicial é personal. |
| `text` | Não | texto | Texto literal de busca ou condição. Confira as regras de comparação da ferramenta. Padrão: "". |

Filtros compostos e limites estão no schema completo. Campos não listados são recusados.

## Exemplo de chamada

Substitua os IDs fictícios pelos da sua instalação, obtidos nas consultas indicadas nos parâmetros.

```json

{
  "name": "preview_rule",
  "arguments": {
    "spaceId": "personal",
    "text": "MERCADO"
  }
}

```

## Interpretar o resultado

Preserve moeda, valores desconhecidos, cobertura e datas de referência informados na resposta. Uma leitura sem registros não comprova ausência de movimentos no banco. Para totais, use agregações de toda a seleção.

O registro desta ferramenta não declara outputSchema. Consulte as regras de resposta no guia de contratos.
