Investimentos · Editar ou configurar · Escrita local

## Efeito da chamada

Esta ferramenta altera dados locais da instalação. Confirme a ação e o espaço com o proprietário antes de enviar confirmed: true e uma chave de idempotência. Ela não altera registros nem executa pagamentos no banco.

## Parâmetros

| Campo | Obrigatório | Tipo | Uso |
| --- | --- | --- | --- |
| `confirmed` | Sim | true | Deve ser true somente depois da confirmação explícita do proprietário. |
| `idempotency_key` | Sim | texto | Chave única para esta solicitação. Reutilize apenas para repetir exatamente a mesma operação. |
| `spaceId` | Sim | texto | Espaço da instalação. Consulte get_spaces; o espaço inicial é personal. |
| `id` | Sim | texto | ID do registro devolvido por get_investments. |
| `amountMinor` | Sim | texto | Valor exato em unidades menores, como string. Em BRL, "10000" significa R$ 100,00. |
| `currency` | Sim | "BRL" / "USD" / "EUR" / "GBP" / "ARS" / "AUD" / "BHD" / "CAD" / "CHF" / "CLP" / "JPY" / "KWD" | Moeda da operação. Valores de moedas diferentes permanecem separados. |
| `date` | Sim | texto | Dia financeiro do registro, em AAAA-MM-DD. |
| `included` | Não | booleano | Define a participação do investimento nos totais patrimoniais. Padrão: true. |
| `name` | Sim | texto | Nome de exibição do registro. |
| `personId` | Não | texto | Titular declarado. Obtenha seu ID em caderninho_status. |
| `type` | Sim | texto | Tipo do registro ou visualização, conforme as opções desta ferramenta. |

Filtros compostos e limites estão no schema completo. Campos não listados são recusados.

## Exemplo de chamada

Substitua os IDs fictícios pelos da sua instalação, obtidos nas consultas indicadas nos parâmetros.

```json

{
  "name": "update_manual_investment",
  "arguments": {
    "confirmed": true,
    "idempotency_key": "docs:update_manual_investment:01",
    "spaceId": "personal",
    "id": "id-exemplo",
    "amountMinor": "10000",
    "currency": "BRL",
    "date": "2026-10-01",
    "name": "Mercado de exemplo",
    "type": "type-exemplo"
  }
}

```

## Interpretar o resultado

Confira o resultado da chamada antes de dar a alteração como concluída. Se a rede falhar, repita somente os mesmos argumentos com a mesma chave. Atualize a leitura se a revisão estiver obsoleta antes de confirmar outra operação.

O registro desta ferramenta não declara outputSchema. Consulte as regras de resposta no guia de contratos.
