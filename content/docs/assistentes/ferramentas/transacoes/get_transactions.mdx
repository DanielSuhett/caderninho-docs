Transações e compras · Consultar · Consulta / prévia

## Efeito da chamada

Consulta ou simula sem gravar alterações financeiras nem iniciar uma importação.

## Parâmetros

| Campo | Obrigatório | Tipo | Uso |
| --- | --- | --- | --- |
| `personId` | Não | texto | Titular declarado. Obtenha seu ID em caderninho_status. |
| `spaceId` | Não | texto | Espaço da instalação. Consulte get_spaces; o espaço inicial é personal. Padrão: "personal". |
| `accountId` | Não | texto | ID de conta devolvido por get_accounts. |
| `cardNumber` | Não | texto | Quatro últimos dígitos do cartão recebidos na identificação da origem. |
| `categoryId` | Não | texto | ID de categoria devolvido por get_categories no mesmo espaço. |
| `currency` | Não | "BRL" / "USD" / "EUR" / "GBP" / "ARS" / "AUD" / "BHD" / "CAD" / "CHF" / "CLP" / "JPY" / "KWD" | Moeda da operação. Valores de moedas diferentes permanecem separados. |
| `direction` | Não | "DEBIT" / "CREDIT" | Direção DEBIT ou CREDIT. Ela não determina, sozinha, despesa ou receita. |
| `from` | Não | texto | Primeiro dia incluído na seleção, em AAAA-MM-DD. |
| `include_ignored` | Não | booleano | Inclui lançamentos marcados como ignorados na seleção. Padrão: false. |
| `status` | Não | "PENDING" / "POSTED" | Estado do registro ou filtro. Use somente as opções aceitas por esta ferramenta. |
| `tagId` | Não | texto | ID de etiqueta devolvido por get_tags no mesmo espaço. |
| `text` | Não | texto | Texto literal de busca ou condição. Confira as regras de comparação da ferramenta. |
| `to` | Não | texto | Último dia incluído na seleção, em AAAA-MM-DD. |
| `uncategorized` | Não | booleano | Somente lançamentos sem categoria efetiva. |
| `cursor` | Não | texto | Cursor recebido na página anterior. Preserve filtros e revisão. |
| `limit` | Não | inteiro | Máximo de registros ou candidatos devolvidos. Confira paginação e cobertura na resposta. Padrão: 100. Máximo: 500. Mínimo: 1. |
| `order` | Não | "id" / "date_desc" | Ordem da lista. date_desc é adequada para consultar movimentos recentes. Padrão: "id". |

Filtros compostos e limites estão no schema completo. Campos não listados são recusados.

## Exemplo de chamada

Substitua os IDs fictícios pelos da sua instalação, obtidos nas consultas indicadas nos parâmetros.

```json

{
  "name": "get_transactions",
  "arguments": {
    "from": "2026-10-01",
    "to": "2026-10-31",
    "limit": 5,
    "order": "date_desc"
  }
}

```

## Interpretar o resultado

Preserve moeda, valores desconhecidos, cobertura e datas de referência informados na resposta. Uma leitura sem registros não comprova ausência de movimentos no banco. Para totais, use agregações de toda a seleção.

O registro desta ferramenta não declara outputSchema. Consulte as regras de resposta no guia de contratos.
