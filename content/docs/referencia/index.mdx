## Origem dos textos

Os textos mantêm o conteúdo original, com links ajustados para este site. Relatos de testes, medições e limites valem para as condições descritas em cada documento.

Um manifesto no repositório dos guias registra o commit de origem, se havia alterações locais e os hashes dos documentos. O mantenedor atualiza essa cópia; o site publicado não acessa o checkout financeiro.

## Origem do catálogo MCP

O catálogo usa as ferramentas, descrições e schemas de `src/contracts`. Os exemplos são validados pelo schema de entrada, sem executar chamadas financeiras.

Consulte o [catálogo navegável](/docs/assistentes/ferramentas) ou baixe o [JSON do registro](/examples/mcp-tools.json) com os contratos completos.
